# Summarise Granola

A Claude Code skill that turns Granola meeting transcripts into detailed, structured summaries -- then files them where you need them.

## Why use this over Granola's built-in notes?

Granola's built-in summaries are quick bullet-point overviews. This skill produces something different: a **chronological narrative** of how the conversation unfolded -- the reasoning behind decisions, who said what, shifts in thinking, and the exact quotes that mattered. The format is designed to help you mentally reconstruct the call days or weeks later, not just skim the headlines.

It also fits into your actual workflow:

- **Creates a Google Doc** you can share or reference
- **Links summaries into your existing 1:1 meeting docs** (optional -- if you keep shared meeting docs with colleagues)
- **Sends call notes** via email draft or Slack DM, so the other person gets the summary without you copying and pasting
- **Files summaries by project** so they're findable later

The summaries are generated by Claude (Opus), which handles nuance, context, and structure well -- especially for longer or more complex conversations where Granola's summaries tend to flatten the detail.

## Prerequisites

- **Claude Code** -- the CLI tool or desktop app ([download here](https://claude.ai/claude-code)). This skill does NOT work in claude.ai chat (web/mobile) -- it needs Claude Code because it reads files from your Mac, runs local scripts, and calls MCP tools.
- [Granola](https://www.granola.so/) desktop app (macOS)
- macOS (Granola stores transcripts locally; the skill reads them from disk)

## Install

Open Terminal and run:

```bash
git clone https://github.com/Aidan-Alexander/summarise-granola.git ~/.claude/skills/summarise-granola
```

## Setup

After installing, open **Claude Code** (not claude.ai chat) and type `/summarise-granola`. The skill will detect it's unconfigured and walk you through setup:

1. **Your name** -- used in summaries, doc titles, and email sign-offs
2. **Meeting doc URLs** (optional) -- if you have shared 1:1 Google Docs and want call summaries linked there, you can provide the URLs during setup. Skip this if you don't use shared meeting docs, or add them later.

Your settings are saved to `config.json` in the skill directory (gitignored, so each person has their own).

## Usage

After a Granola call, open **Claude Code** and type:

```
/summarise-granola
```

If your call ended within the last 30 minutes, it's picked up automatically. Otherwise you'll see a list of recent calls to choose from.

> **Note:** This must be run in Claude Code (CLI or desktop app), not in claude.ai chat. The skill needs access to your local filesystem to read Granola transcripts.

## What it does

1. Extracts the raw transcript from Granola
2. Creates a structured, chronological summary as a Google Doc
3. (If configured) Links the summary from your 1:1 meeting doc
4. (Optional) Sends call notes via email draft or Slack DM
5. (Optional) Creates a tidied transcript in the background

## Configuration

Edit `config.json` to add or update settings:

```json
{
  "user_name": "Your Name",
  "meeting_docs": {
    "Person Name": {
      "url": "https://docs.google.com/document/d/.../edit"
    }
  }
}
```

See `config.json.example` for the template.

### Adding meeting docs later

You can add meeting doc URLs at any time by editing `config.json`. When you summarise a call with someone whose meeting doc isn't configured, the skill will search Google Drive for it and offer to save the URL for next time.

## MCP integrations

The skill works best with these MCP tools connected in Claude Code:

- **Google Drive** -- for creating summary Google Docs
- **Gmail** -- for sending call notes as email drafts
- **Slack** -- for sending call notes as DMs

The skill works without these (summaries are saved locally as markdown), but the sharing features require them.

## Advanced: formatted Google Docs (optional)

By default, summaries are saved as plain-text Google Docs -- readable and shareable but without rich formatting (bold, headings render as ALL CAPS, etc).

If you want fully formatted Google Docs -- with proper headings, bold/italic, lists, links, and tables -- you can deploy a small Google Apps Script web app and add its URL to your `config.json`. The setup takes about 5 minutes.

See [`references/apps-script/README.md`](references/apps-script/README.md) for instructions.
